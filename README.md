# Templar Knight for Omarchy

A dark crusader-inspired Omarchy theme with iron-black surfaces, parchment text,
deep red accents, and cinematic Templar wallpapers.

Made by **Agent Doulos**.

## Preview

![Templar Knight preview](preview.png)

## Install

```bash
omarchy theme install https://github.com/VilhelmKMoller/omarchy-theme-templar-knight
omarchy theme set templar-knight
```

For a local checkout:

```bash
mkdir -p ~/.config/omarchy/themes
cp -a . ~/.config/omarchy/themes/templar-knight
omarchy theme set templar-knight
```

## Included

- `colors.toml` for Omarchy's generated app theme colors
- Hyprland active border styling
- btop, Chromium, VS Code, keyboard, icon, and lock-screen theme files
- Two cinematic wallpapers:
  - `Battle Worn Templar`
  - `Kneeling Templar Heavenly Host`

## Notes

The theme is designed for Omarchy and should be installed through
`omarchy theme install` when used from a public git repository.
